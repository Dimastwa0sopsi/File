# Сервер и база данных

## Что внутри
- `server.js` — WebSocket-сервер + SQLite (`better-sqlite3`). Протокол совпадает с клиентом игры:
  `login` → `login_success`, `move`, `players_list`, `chat`, `error`; дополнительно `set_plate` и поля `car_id` / `car_number`.
- `colab_setup.py` — ячейка Colab: монтирует Google Диск, ставит зависимости, поднимает сервер и ngrok-туннель.
- `colab_admin.py` — **мини админ-панель в выходной ячейке Colab**: кнопки для денег, бана, кика, телепорта, выдачи машины и объявлений. В самой игре никакой админки нет.

## Быстрый старт в Colab
1. Загрузите `server.js` в `MyDrive/MyGame/`.
2. Откройте новую ячейку и вставьте код из `colab_setup.py`, впишите токен ngrok.
3. Скопируйте выведенный адрес `wss://...` и вставьте его в меню игры («Адрес сервера»), либо в `VITE_ONLINE_URL`.

## Админ-панель в Colab
1. Запустите `colab_setup.py` — он поднимет сервер и запомнит `ADMIN_TOKEN` (по умолчанию `losgorod-admin`).
2. Создайте новую ячейку и вставьте содержимое `colab_admin.py`.
3. Управляйте кнопками:
   - **Деньги** — задать сумму или добавить (+10 000 / +100 000 / +1 000 000), списать всё;
   - **Модерация** — забанить (с причиной), разбанить, кикнуть;
   - **Телепорт** — отправить игрока на координаты X/Z или на точку появления (срабатывает сразу, если игрок в сети);
   - **Транспорт** — выдать машину и номерной знак;
   - **Объявления** — сообщение от СИСТЕМЫ в общий чат, очистка чата;
   - **Опасное** — удалить аккаунт (с подтверждением);
   - **Игроки** — таблица: статус, деньги, машина, координаты, бан.

Панель ходит в локальный HTTP-API сервера: `GET /admin/state` и `POST /admin/action` с `?token=...`.
Игра этот API не использует — права администратора в клиенте полностью убраны.

## Схема базы (SQLite)
| Таблица | Поля |
|---|---|
| `players` | id, name (уникальный), gender, money, car_id, car_number, house_id, pos_x, pos_z, pos_rot, banned, ban_reason, updated_at |
| `chat_log` | id, name, text, t |

## Почему SQLite на Google Диске — рабочий вариант
- База — один файл `game.db` в `MyDrive/MyGame`, поэтому данные не теряются при перезапуске Colab.
- WAL-режим + запись `move` на каждое сообщение даёт до ~15 записей/сек на игрока; для 10–20 игроков это нормально.
- Если игроков станет больше, база легко переносится в Postgres (Supabase) — структура таблиц та же, меняется только драйвер.
- Токен ngrok храните приватно: с ним можно перехватить туннель.
