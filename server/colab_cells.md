# Colab: одна ячейка — сервер, туннель и админ-панель

Всё живёт в одном файле: **`server/colab_cell.py`** (около 800 строк). Ячейка сама:
монтирует Диск, качает `server.js` с зеркал, ставит `ws`/`better-sqlite3`/`pyngrok`, поднимает
сервер, поднимает ngrok, публикует адрес в `server/live.json` и рисует админ-панель
(игроки, 100 кнопок, чат, сервер и логи).

## Порядок действий

1. Откройте [colab.research.google.com](https://colab.research.google.com) → «Новая запись».
2. Создайте ячейку и вставьте **весь** текст `server/colab_cell.py`.
3. В блоке `CFG` впишите:
   - `NGROK_TOKEN` — токен с [dashboard.ngrok.com](https://dashboard.ngrok.com/get-started/your-authtoken) (без него не будет туннеля для онлайн-игры);
   - `GH_TOKEN` — необязательно, fine-grained token с правом `contents: write` (тогда `live.json` обновляется сам);
   - `NGROK_DOMAIN` — необязательно, статический домен ngrok (адрес сервера перестаёт меняться).
4. Запустите ячейку (Shift+Enter). Панель появится прямо под выводом.

Повторный запуск безопасен: `server.js` перекачивается только если изменился, работающий
сервер переиспользуется. Если на порту остался процесс со старым кодом, ячейка это увидит
(сверяет отпечаток `/version`) и заменит его сама — вручную убивать процессы не нужно.

## Что делает панель

| Вкладка | Что внутри |
| --- | --- |
| 👥 Игроки | поиск по нику, фильтр «все / в сети / офлайн / в бане», сортировка по нику, деньгам, варнам; карточка игрока; быстрые кнопки: деньги, лечение, кик, варн, мут, бан, телепорт в больницу/полицию/на пляж, выдача машины и номера |
| 🎛 100 кнопок | весь каталог `ADMIN_ACTIONS` из `server.js`, разложенный по 8 группам: деньги, модерация, телепорт, транспорт, чат, игрок, сервер, события |
| 📢 Чат | объявление всем игрокам, лента последних сообщений, очистка чата |
| 🖥 Сервер | адрес туннеля и постоянная ссылка для игроков, публикация `live.json`, перезапуск сервера, инфо/бэкап/размер базы, техработы, статистика, живые логи |

Общие поля (причина бана, X/Z, модель машины, номер, дом, текст объявления и галочка
«Разрешить опасные действия») — в панели над вкладками: они нужны сразу нескольким вкладкам.
Опасные действия без галочки не выполняются.

## Если что-то не так

| Симптом | Что делать |
| --- | --- |
| `Не удалось скачать server.js` | проверьте интернет рантайма и ещё раз запустите ячейку; зеркала идут по цепочке jsDelivr → fastly → Statically → raw.githack |
| `Сервер не поднялся` | ячейка печатает конец `server.log`; почти всегда помогает `RESTART='1'` и повторный запуск |
| «Порт всё ещё занят» | в меню Colab «Среда выполнения → Перезапустить среду выполнения», затем запустить ячейку снова |
| В игре «соло-режим» | нет живого туннеля: проверьте `NGROK_TOKEN`, затем кнопку «📡 Опубликовать» на вкладке «🖥 Сервер» |
| Панель пустая / «Нет связи с сервером» | сервер упал или перезапускается: вкладка «🖥 Сервер» → «Логи» |
| Игрок не находится в списке | нажмите «🔄 Обновить»: список берётся из базы, а не из онлайна |
| Кнопка отвечает «Игрок не в сети» | действие требует подключённого игрока (лечить, кикнуть, убить, телепортировать) — это нормально для офлайн-аккаунта |
| «Туннель не найден» при публикации | ngrok не поднят: впишите `NGROK_TOKEN` и запустите ячейку заново |

## Совместимость

`server/colab_setup.py` оставлен как тонкая обёртка: он скачивает `colab_cell.py` с тех же
зеркал и выполняет его. Новые инструкции — только про `colab_cell.py`.
