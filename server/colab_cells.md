# Colab: одна ячейка — сервер, туннель и админ-панель (онлайн и офлайн)

Всё живёт в одном файле: **`server/colab_cell.py`**. Ячейка сама:
монтирует Диск, берёт `server.js` (папка игры → кэш → зеркала), ставит `ws`/`better-sqlite3`/`pyngrok`
при необходимости, поднимает сервер, поднимает ngrok (если есть сеть), публикует адрес в
`server/live.json` и рисует админ-панель: выбор игрока, деньги, предметы и инвентарь,
100 кнопок, чат, сервер и логи.

## Порядок действий

1. Откройте [colab.research.google.com](https://colab.research.google.com) → «Новая запись».
2. Создайте ячейку и вставьте **весь** текст `server/colab_cell.py`.
3. В блоке `CFG` впишите:
   - `NGROK_TOKEN` — токен с [dashboard.ngrok.com](https://dashboard.ngrok.com/get-started/your-authtoken) (без него не будет туннеля для онлайн-игры);
   - `GH_TOKEN` — необязательно, fine-grained token с правом `contents: write` (тогда `live.json` обновляется сам);
   - `NGROK_DOMAIN` — необязательно, статический домен ngrok (адрес сервера перестаёт меняться).
4. Запустите ячейку (Shift+Enter). Панель появится прямо под выводом.

Повторный запуск безопасен: `server.js` перекачивается только если он устарел, работающий
сервер переиспользуется. Если на порту остался процесс со старым кодом, ячейка это увидит
(сверяет отпечаток `/version`) и заменит его сама — вручную убивать процессы не нужно.

## Офлайн-режим

Интернет не обязателен — ячейка сама это понимает и ничего не настраивает:

| Шаг | Что делает без сети |
| --- | --- |
| `server.js` | берёт из папки игры; если там нет — из кэша `server.cache.js` (пишется при каждом удачном скачивании) |
| `npm install` | пропускает, если модули уже лежат в `node_modules` папки игры (Google Диск сохраняет их между сессиями) |
| `pyngrok` | не ставит и не поднимает туннель — печатает «работаем без туннеля» |
| `live.json` | не публикует: постоянная ссылка не меняется, публикация догонит при первом онлайне |
| панель | работает полностью: деньги, предметы, инвентарь, телепорты, «выгнать всех» |

Принудительно включить офлайн: `CFG['OFFLINE'] = '1'` (сеть не трогаем вообще).
Принудительно обновить сервер: `CFG['FORCE_UPDATE'] = 1`. Закрепить конкретный коммит
для зеркал: `CFG['PIN'] = '7c918aa'`.

Первый запуск всё-таки должен быть с сетью — иначе нечего скачивать и нечем ставить модули.
Кэш `server.cache.js` и `node_modules` остаются в папке игры на Диске, поэтому дальше
офлайн запускается сколько нужно раз.

## Что делает панель

| Вкладка | Что внутри |
| --- | --- |
| 👥 Игроки | выбор игрока выпадающим списком «Игрок» (синхронизирован со списком слева), поиск, фильтр «все / в сети / офлайн / в бане», сортировка по нику, деньгам, варнам; карточка игрока; блок «Одним нажатием»: 💰 Миллион, 💵 Ровно 1 000 000, 🎁 Аптечка ×5, 👢 Выгнать всех; модерация: варн, мут, кик, бан, разбан |
| 💵 Деньги | сумма, режим «начислить / списать / установить», выдача выбранному и всем онлайн, пресеты от `$1 000` до `$1 000 000`, потолок, защита от накрутки, журнал действий |
| 🎁 Предметы | каталог из 60 предметов по 9 группам с поиском, количество, «🎁 Выдать» / «🗑 Забрать», всем онлайн, готовые наборы (стартовый, рыбаку, оружие, автомобилисту, еда), «🎒 Показать инвентарь» и «🗑 Очистить инвентарь» |
| 🎛 100 кнопок | весь каталог `ADMIN_ACTIONS` из `server.js`, разложенный по 8 группам: деньги, модерация, телепорт, транспорт, чат, игрок, сервер, события |
| 📢 Чат | объявление всем игрокам, лента последних сообщений, очистка чата |
| 🖥 Сервер | адрес туннеля и постоянная ссылка для игроков, публикация `live.json`, перезапуск сервера, инфо/бэкап/размер базы, техработы, статистика, живые логи |

Общие поля (причина бана, X/Z, модель машины, номер, дом, текст объявления и галочка
«Разрешить опасные действия») — в панели над вкладками: они нужны сразу нескольким вкладкам.
Опасные действия без галочки не выполняются. Поле «К кому» — цель телепорта «к другому игроку».

## Текстовая панель (если нет ipywidgets)

Когда виджеты не ставятся (например, нет сети), ячейка сама включает `panel_text()`.
Вернуться в неё позже: `panel_text()` в новой ячейке.

```
players              список игроков с номерами
sel 3                выбрать игрока №3 (или sel Вася)
give medkit 5        выдать выбранному          take medkit 2   забрать
kit kit_fish         набор                    clear           очистить инвентарь
inv                  инвентарь выбранного
money 500 sub        деньги выбранному (add | sub | set)
mill                 миллион выбранному
tp beach             телепорт выбранного (точки — команда points)
tpme Вася            выбранного к другому игроку
kickall              выгнать всех онлайн (спросит подтверждение)
kick / ban / warn / heal / kill / info / freeze / unfreeze / respawn
moneyall 10000       деньги всем онлайн
actions [группа]     все 100 кнопок          act <id> [k=v]  любая кнопка
log [строк]          журнал панели             exit           выйти
```

## Если что-то не так

| Симптом | Что делать |
| --- | --- |
| `Нет рабочего server.js и нет сети` | первый запуск должен быть с интернетом; либо положите `server.js` в папку игры вручную |
| `Каталог предметов не загрузился: 404` | сервер старый: ячейка теперь проверяет файл по отделам, просто запустите её снова; упорно повторяется — `FORCE_UPDATE=1` |
| `Сервер не поднялся` | ячейка печатает конец `server.log`; почти всегда помогает `RESTART='1'` и повторный запуск |
| `Нет модулей: ws, better-sqlite3` | нужен один запуск с интернетом: модули останутся в папке игры и дальше работают офлайн |
| «Порт всё ещё занят» | в меню Colab «Среда выполнения → Перезапустить среду выполнения», затем запустить ячейку снова |
| В игре «соло-режим» | нет живого туннеля: проверьте `NGROK_TOKEN`, затем кнопку «📡 Опубликовать» на вкладке «🖥 Сервер» |
| Панель пустая / «Нет связи с сервером» | сервер упал или перезапускается: вкладка «🖥 Сервер» → «Логи»; либо `panel_text()` |
| Игрок не находится в списке | нажмите «🔄 Обновить»: список берётся из базы, а не из онлайна |
| Кнопка отвечает «Игрок не в сети» | действие требует подключённого игрока (лечить, кикнуть, убить, телепортировать) — это нормально для офлайн-аккаунта |
| «Туннель не найден» при публикации | ngrok не поднят: впишите `NGROK_TOKEN` и запустите ячейку заново |

## Совместимость

`server/colab_setup.py` оставлен как тонкая обёртка: он скачивает `colab_cell.py` с тех же
зеркал и выполняет его. Новые инструкции — только про `colab_cell.py`.
