# Лос-Город — браузерный симулятор жизни с открытым миром

React + TypeScript + Vite + Three.js + Tailwind. Всё (модели, текстуры, звук) генерируется процедурно — внешних игровых файлов нет.

## Запуск
```bash
npm install
npm run dev      # разработка: http://localhost:5173
npm run build    # production-сборка в dist/index.html (один файл)
npx tsc --noEmit # проверка TypeScript
```

## Архитектура (src/game)
| Модуль | Назначение |
|---|---|
| `config.ts` | Единый источник размеров мира (N = 18, проверка индексов кварталов), RNG, настройки |
| `worldgen.ts` | Генерация раскладки (чистые данные): дорожный граф, кварталы, спецздания, деревни, промзона, ферма, река, пляж; проверка «нет препятствий на дорогах»; A* |
| `worldMesh.ts` | Построение 3D-мира: чанки 120 м, объединённая геометрия по материалам, инстансы светофоров и пшеницы, поэтапная асинхронная загрузка |
| `geom.ts`, `textures.ts` | Общие геометрии, батчер-объединитель, процедурные Canvas-текстуры и кэш материалов |
| `vehicleModel.ts` | Модели транспорта (капот, бамперы, двери, зеркала, стёкла, салон, диски…), отрываемые детали, тюнинг |
| `vehicles.ts` | Физика игрока (передачи, стант, вертолёт), ИИ-водитель по маршруту A* со светофорами и трафиком |
| `character.ts` | Персонажи с лицами, причёсками, одеждой и позами |
| `npc.ts` | Пешеходы: тротуары и зебры по сигналу светофора, деревни, пляж (уходят ночью), обход препятствий (lookahead + объезд углами), реакции на удары |
| `interiors.ts` | 34 индивидуальных интерьера: магазины (город/деревня), аптека и оружейный грузовик, госучреждения, ТЦ с магазинами, подъезд, квартиры эконом/средний/люкс, дома с сенями, офис и кабинет врача |
| `collision.ts` | Пространственная сетка AABB, высота пола/ступени, выталкивание, лучи (пули и камера) |
| `game.ts` | Игровой цикл, игрок, интерьеры и точки выхода, работа, полиция, такси, автопилот, экономика, мини-карта, адаптивное качество |
| `state.ts` | Состояние, экономика авто, версионированное сохранение и миграция |
| `net.ts` | Онлайн-клиент WebSocket с автопереподключением, `?srv=` и `normalizeServerUrl` |
| `discovery.ts` | Поиск живого сервера: `server/live.json` из репозитория (3 зеркала) → сохранённый адрес → встроенный, каждый кандидат проверяется подключением |
| `mapdraw.ts` | Векторная мини-карта и большая карта, GPS-маршрут, значки |
| `audio.ts`, `input.ts` | WebAudio-звук; клавиатура по физическим кодам (работает в русской раскладке), мышь, сенсор |

UI (src/ui): главное меню, гайд, настройки, HUD, телефон, панели магазинов, большая карта, сенсорное управление. React-состояние HUD обновляется ~8 раз в секунду, Three.js работает в своём цикле.

## Обновление: одна постоянная ссылка, меню из одной кнопки, промо-машина «Лос-X»
- **Одна ссылка навсегда: `https://dimastwa0sopsi.github.io/File/`.** Адрес сервера игрок больше нигде не вводит. При запуске клиент сам ищет живой сервер (`src/game/discovery.ts`): читает опубликованный адрес из `server/live.json` (raw.githubusercontent → Statically → jsDelivr, каждый со своим `updated`), затем сохранённый в браузере, затем встроенный — и **проверяет каждого кандидата настоящим WebSocket-подключением**. Мёртвый туннель никогда не «залипает»: свежий адрес в `live.json`, который не отвечает, пропускается, берётся следующий живой. Найденный адрес кэшируется на 5 минут. Если живого сервера нет вообще — игра не падает, а стартует в одиночном режиме.
- **Сервер сам публикует свой адрес.** `server.js` при заданном `GH_TOKEN` (право `contents:write`) обновляет `server/live.json` в репозитории через GitHub API при старте (до шести попыток, туннель поднимается не сразу), а также по запросу `GET /admin/publish?token=…`. В Colab это делает кнопка **📡 Постоянная ссылка** — после неё новый туннель уже известен всем игрокам по прежней ссылке. Для полной неподвижности адреса в панель добавлено поле «Домен» — статический домен ngrok бесплатного тарифа (`ngrok.connect(..., domain=…)`), тогда `live.json` можно вообще не обновлять.
- **Меню — одна кнопка.** На стартовом экране осталась только **▶ Играть**: убраны «⚙ Настройки», «❓ Как играть», шаги «выбор режима», быстрый вход, формы логина/регистрации, строка «Сервер: …» и все пояснения. «Играть» сам решает, куда идти: живой сервер найден — общий мир, нет — одиночная игра. Ник берётся из аккаунта/прошлой сессии, иначе `Игрок123`. Настройки и «Онлайн» остались внутри игры (Esc / 🌐 / планшет).
- **Подсказки в игре убраны.** Сообщения «🎥 V — сменить вид», «R — сменить», тексты клавиш у шкалы станта, «двигайтесь, чтобы прервать», «X — трюк» у аренды удалены — остались только контекстные действия вроде «E — заправить».
- **Промо-машина «Лос-X» (`/promo` → код `X`).** Купить её нельзя: она выдаётся только промокодом и только один раз на аккаунт. Характеристики: **378 км/ч** (`maxSpeed 105` — быстрее «Скорпиона V12» с 331), разгон 26, **никогда не ломается** (`unbreakable`: состояние всегда 100 %, бак не пустеет, детали не отлетают, двигатель не дымит, урон от столкновений не проходит), и **стант на X доступен обычному кузову** (`stunt` + `Vehicle.canStunt`; вилли — X + газ, стоппи — X + тормоз; запас до срыва трюка увеличен).

## Обновление: вход в онлайн больше не блокируется, адрес сервера — кнопкой в Colab
- **Почему не пускало на сервер.** Причины были в трёх местах: (1) сервер отказывал вторым входом под тем же ником (`Ник «…» уже в сети`), а после перезагрузки страницы старый сокет ещё висел — игрок оставался снаружи; (2) закрытие старого сокета снимало регистрацию новой сессии (`active.delete(ws.playerId)` по общему id), из-за чего игрок «пропадал» из онлайна; (3) привязка ника к устройству (`token`) навсегда закрывала вход после чистки `localStorage` или смены браузера.
  Теперь: новый вход **перехватывает** старую сессию (старому сокету уходит `code: 'replaced'`), закрытие сокета снимает только свою запись, привязка устройства по умолчанию мягкая (новое устройство забирает ник, в лог пишется строка `[login] … новое устройство`), строгая включается `STRICT_DEVICE=1`. Ошибки сервера приходят с кодом: `banned`, `maintenance`, `device`, `replaced`, `busy`, `name`.
- **Клиент не умирает от временных ошибок.** «Техработы», «ник за другим устройством» и «вход из другого окна» показываются в окне «Нет связи» с кнопкой **🔄 Повторить вход** (`net.ts: softFail/retryLogin`), «ник занят» на старом сервере переподключается сам (до трёх раз).
- **Адрес сервера из Colab вставляется как есть.** Раньше в поле «Адрес сервера» принимались только `ws://`/`wss://`, а ngrok даёт `https://…` — адрес молча отбрасывался и игра шла на зашитый (часто уже мёртвый) адрес. Теперь `https://` превращается в `wss://`, голый хост — в `wss://host`, лишние слэши убираются (`net.ts: normalizeServerUrl`). Плюс поддержана ссылка `?srv=wss://…` — она применяется один раз и запоминается.
- **Colab-панель: блок «🔗 Адрес сервера для игроков».** Кнопка «Взять адрес туннеля» берёт его у ngrok (локальный API 4040) или у сервера (`/admin/tunnel`, учитывает `PUBLIC_URL`); «🌐 Поднять туннель (ngrok)» поднимает туннель прямо из панели (нужен токен ngrok). Панель показывает готовый адрес для поля в игре и ссылку вида `https://dimastwa0sopsi.github.io/File/?srv=wss%3A//…`, по которой адрес подставляется автоматически. `colab_setup.py` теперь передаёт `PUBLIC_URL` серверу.
- **Сервер: `/health`** (без токена) — онлайн, аптайм, техработы; `/admin/tunnel` — публичный адрес; в лог пишутся входы и выходы игроков, чтобы видеть это в окне логов.

## Обновление: онлайн-состояние игроков, машины без «призраков», рестарт и логи из Colab
- **Машины в онлайне исправлены по-настоящему.** Причина «машина как бы есть, как бы нет» была не в отрисовке: протокол расширенного состояния (`§LG`: машина, место в салоне, поза, внешность, помещение) включался только после того, как клиент получал такое сообщение от другого игрока, а наш сервер `server.js` такие сообщения вообще не пересылал — режим не включался никогда. В итоге о чужом игроке был известен только его `car_id` из базы, и рядом с пешеходом рисовалась его машина.
  Теперь сервер сообщает о своих возможностях в `login_success` (`caps`), клиент включает расширенное состояние сразу при входе (`net.ts`), а для старых серверов остался один пробный пакет-эхо. Сервер пересылает `§`-сообщения целиком (до 20 000 символов, раньше резались до 200 и ломались) и не пишет их в историю чата. Следствие: водитель всегда сидит в своей машине, пассажир — на своём месте, позы/внешность/помещения других игроков снова работают.
- **`players_list` больше не содержит поле `vehicle`** (устаревший `car_id` из базы) — именно оно и было источником машины-призрака у старых сборок клиента. Список игроков теперь рассылается не чаще 4 раз в секунду вместо 15 (раньше полный список уходил всем на каждое сообщение `move`).
- **Админ-панель Colab: рестарт сервера и окно логов.** Кнопка «🔁 Перезапустить сервер» гасит и поднимает `node server.js` прямо из ноутбука и ждёт ответа `/admin/actions`; «📜 Логи сервера» показывает хвост `server.log` в тёмном окне (ошибки красным, предупреждения жёлтым), есть фильтр «только ошибки», выбор 40/120/400 строк, автообновление раз в 2 секунды и очистка лога.

## Онлайн-режим
Клавиша **Ё** (`) или планшет → «Онлайн»: окно входа с ником (2–16 символов) и выбором пола. В онлайне работает всё, что есть в одиночной игре (деньги, работа, магазины, жильё, машины, розыск). Прогресс и последнее место (включая квартиру/здание) хранятся отдельно в `localStorage['losgorod_save_online']`; повторное **Ё** сохраняет онлайн и возвращает одиночную игру.
- Пассажир: подойти к машине другого игрока и нажать **F** — занимается свободное место (у седанов 4 места, автобус 8, мотоцикл 2). F — выйти. Если водитель выходит, пассажир высаживается.
- Бой между игроками: удары и пули отправляют событие `hit`, урон применяет клиент жертвы (с учётом блока). При потере сознания рассылается `dead` — лента убийств в чате.
- Игроки в помещениях видны только тем, кто в том же помещении.

Протокол сервера (определён опытным путём):
- сервер → `{"type":"init","id":N,"players":{id:{x,y,color,name}}}`, затем `{"type":"players",...}`;
- клиент → `{"type":"move","x":X,"y":Z}` — позиция для карты;
- клиент → `{"type":"chat","text":"..."}` → рассылка `{"type":"chat","id","name","text"}`.
Полное состояние (ник, внешность, поза, оружие, машина, место пассажира, помещение, здоровье) — чат-сообщение `§LG`+JSON ~8 раз/с; события (`shot`, `hit`, `dead`) — `§LGE`+JSON. В окне чата они не показываются.

## Боевая система (`combat.ts`, `npc.ts`)
- Рукопашный бой: серия джеб → кросс → хук (хук сильнее и может сбить с ног), мягкий захват ближайшей цели, рывок к цели, блок (ПКМ) −75% урона, оглушение, нокдаун и подъём.
- NPC: бьют сериями, кружат вокруг, ставят блоки, шатаются, падают и встают, трусливые убегают; свидетели пугаются.
- Пистолет: вид из-за плеча (ПКМ), прицел в центре экрана, разброс, магазин 12 + перезарядка R, попадание в голову ×3, пули не проходят сквозь стены (проверка от ствола до точки), урон NPC, игрокам и машинам, трассеры, вспышки, искры, кровь, следы от пуль; на телефоне доводка прицела.

## Обновление: меню, ворота на петлях, прижим к стене, выхлоп
- **Новое стартовое меню**: «Играть», «Настройки», «Как играть». «Играть» → выбор режима: **одиночная игра** запускается сразу (сюжет, без входа), **онлайн** — по логину и паролю. Внизу онлайна — быстрый вход для аккаунтов, которые уже входили на этом устройстве (одна кнопка, без пароля), рядом крестик для удаления ненужного аккаунта вместе с его прогрессом. Аккаунты по-прежнему хранятся в браузере, пароль — только хэшем с солью (`accounts.ts`: `quickLogin`, `removeAccount`).
- **Ворота на петлях**: все створки во дворах домов, у гаражных кооперативов, завода и фермы стали динамическими (`worldMesh.ts` собирает их одним `InstancedMesh`, `game.ts → updateGates`). Подъезжаете — створки распахиваются внутрь двора за полсекунды, отъехали — закрываются. У ворот нет коллайдера, поэтому машина проходит их без урона.
- **Машины крепче**: урон кузова от ударов снижен почти втрое, детали отлетают только при сильном ударе, урон водителю от аварии меньше. До капитального ремонта теперь хватает нескольких аварий.
- **Прижим к стене спиной (Q)** как в GTA V: одно нажатие — персонаж встаёт спиной к ближайшей стене и смотрит от неё, A/D — шаг вдоль стены (поза `coverwalk`), при прицеливании — выглядывание (`coveraim`), W — отойти, Пробел — отскок в сторону от стены. Повторное Q или отход/прыжок/посадка в машину/вода выводят из укрытия. На телефоне — кнопка 🧱/🚪.
- **Больше анимаций**: +6 поз — поклон, честь, «показать», «задуматься», разминка, радость (всего 16, B или /e 1–16), плюс новая поза прижима к стене.
- **Выхлоп и отстрел**: при газе из трубы идёт дымок, на высоких оборотах слышны хлопки с язычками пламени (`spawnExhaust`, `spawnBackfire`, `sound.backfire`).
- **Камера на огромной скорости** слегка покачивается (крен, кивок, микроподъём и рост FOV), сильнее — на мотоцикле и самокате.
