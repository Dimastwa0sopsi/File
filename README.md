# Лос-Город — браузерный симулятор жизни с открытым миром

React + TypeScript + Vite + Three.js + Tailwind. Всё (модели, текстуры, звук) генерируется процедурно — внешних игровых файлов нет.

## Запуск
```bash
npm install
npm run dev      # разработка: http://localhost:5173
npm run build    # production-сборка в dist/index.html (один файл)
npx tsc --noEmit # проверка TypeScript
```

## Архитектура (src/game)
| Модуль | Назначение |
|---|---|
| `config.ts` | Единый источник размеров мира (N = 18, проверка индексов кварталов), RNG, настройки |
| `worldgen.ts` | Генерация раскладки (чистые данные): дорожный граф, кварталы, спецздания, деревни, промзона, ферма, река, пляж; проверка «нет препятствий на дорогах»; A* |
| `worldMesh.ts` | Построение 3D-мира: чанки 120 м, объединённая геометрия по материалам, инстансы светофоров и пшеницы, поэтапная асинхронная загрузка |
| `geom.ts`, `textures.ts` | Общие геометрии, батчер-объединитель, процедурные Canvas-текстуры и кэш материалов |
| `vehicleModel.ts` | Модели транспорта (капот, бамперы, двери, зеркала, стёкла, салон, диски…), отрываемые детали, тюнинг |
| `vehicles.ts` | Физика игрока (передачи, стант, вертолёт), ИИ-водитель по маршруту A* со светофорами и трафиком |
| `character.ts` | Персонажи с лицами, причёсками, одеждой и позами |
| `npc.ts` | Пешеходы: тротуары и зебры по сигналу светофора, деревни, пляж (уходят ночью), реакции на удары |
| `interiors.ts` | 26 индивидуальных интерьеров: магазины, госучреждения, ТЦ с отдельными магазинами, подъезд, квартиры эконом/средний/люкс, дома с сенями |
| `collision.ts` | Пространственная сетка AABB, высота пола/ступени, выталкивание, лучи (пули и камера) |
| `game.ts` | Игровой цикл, игрок, интерьеры и точки выхода, работа, полиция, такси, автопилот, экономика, мини-карта, адаптивное качество |
| `state.ts` | Состояние, экономика авто, версионированное сохранение и миграция |
| `net.ts` | Онлайн-клиент WebSocket (`wss://sandbank-economic-zeppelin.ngrok-free.dev`) с автопереподключением |
| `mapdraw.ts` | Векторная мини-карта и большая карта, GPS-маршрут, значки |
| `audio.ts`, `input.ts` | WebAudio-звук; клавиатура по физическим кодам (работает в русской раскладке), мышь, сенсор |

UI (src/ui): главное меню, гайд, настройки, HUD, телефон, панели магазинов, большая карта, сенсорное управление. React-состояние HUD обновляется ~8 раз в секунду, Three.js работает в своём цикле.

## Проверки
`scripts/worldtest.ts` и `scripts/simtest.ts` запускают модули игры в Node (без WebGL):
```bash
npx esbuild scripts/simtest.ts --bundle --platform=node --outfile=/tmp/st.cjs && node /tmp/st.cjs
```
Проверяется: сетка 18×18, отсутствие препятствий на дорогах, связность маршрутов до всех деревень/промзоны/пляжа/фермы, построение всех интерьеров (спавн и точки дверей не в стенах), все модели транспорта и отрыв деталей, остановка ИИ на красный, нейтраль без разгона, стант только у мотоциклов, полёт и посадка вертолёта, погоня полиции, пешеходы не ходят по проезжей части, пляж пустеет ночью.

## Онлайн-режим
Клавиша **Ё** (`) или планшет → «Онлайн»: окно входа с ником (2–16 символов) и выбором пола. В онлайне работает всё, что есть в одиночной игре (деньги, работа, магазины, жильё, машины, розыск). Прогресс и последнее место (включая квартиру/здание) хранятся отдельно в `localStorage['losgorod_save_online']`; повторное **Ё** сохраняет онлайн и возвращает одиночную игру.
- Пассажир: подойти к машине другого игрока и нажать **F** — занимается свободное место (у седанов 4 места, автобус 8, мотоцикл 2). F — выйти. Если водитель выходит, пассажир высаживается.
- Бой между игроками: удары и пули отправляют событие `hit`, урон применяет клиент жертвы (с учётом блока). При потере сознания рассылается `dead` — лента убийств в чате.
- Игроки в помещениях видны только тем, кто в том же помещении.

Протокол сервера (определён опытным путём):
- сервер → `{"type":"init","id":N,"players":{id:{x,y,color,name}}}`, затем `{"type":"players",...}`;
- клиент → `{"type":"move","x":X,"y":Z}` — позиция для карты;
- клиент → `{"type":"chat","text":"..."}` → рассылка `{"type":"chat","id","name","text"}`.
Полное состояние (ник, внешность, поза, оружие, машина, место пассажира, помещение, здоровье) — чат-сообщение `§LG`+JSON ~8 раз/с; события (`shot`, `hit`, `dead`) — `§LGE`+JSON. В окне чата они не показываются.

## Боевая система (`combat.ts`, `npc.ts`)
- Рукопашный бой: серия джеб → кросс → хук (хук сильнее и может сбить с ног), мягкий захват ближайшей цели, рывок к цели, блок (ПКМ) −75% урона, оглушение, нокдаун и подъём.
- NPC: бьют сериями, кружат вокруг, ставят блоки, шатаются, падают и встают, трусливые убегают; свидетели пугаются.
- Пистолет: вид из-за плеча (ПКМ), прицел в центре экрана, разброс, магазин 12 + перезарядка R, попадание в голову ×3, пули не проходят сквозь стены (проверка от ствола до точки), урон NPC, игрокам и машинам, трассеры, вспышки, искры, кровь, следы от пуль; на телефоне доводка прицела.

Проверки: `scripts/combattest.ts` (бой NPC, лучи), `scripts/nettest.ts` (ник, посадка, удары, выстрелы, смерть на реальном сервере; нужен пакет `ws`).

## Обновление: общий мир, жильё, автобазар, поддержка
- **Общие NPC** (`npc.ts`): каждый клиент симулирует пешеходов вокруг себя и рассылает снимок (`§LGN`, 4 раза/с, ~450 байт на 12 NPC); NPC других игроков отображаются «марионетками» с той же внешностью (детерминированный seed). Удар/выстрел по чужому NPC отправляется владельцу (`pedhit`), NPC дерётся именно с ударившим игроком.
- **Недвижимость**: купленные дома — красные на карте, свободные — зелёные; замок (L у двери / планшет), гости могут зайти в открытый дом; в онлайне игрок появляется дома (`spawnHome`).
- **Автобазар**: продавцы-NPC и 8 размеченных мест продажи. Объявление видят NPC-покупатели (вероятность зависит от цены к оценке) и игроки онлайн — покупка через `buyreq`/`sold` с задатком и возвратом при отказе/таймауте.
- **Главное шоссе** (z = 540): вдоль него 14 автомехаников, 13 автосалонов, магазины, кафе, аптеки.
- **Угон**: 74 припаркованные машины (сигнализация 35%), машины в потоке — водитель выбрасывается.
- **Такси между игроками**: купите такси в автосалоне; пассажир платит водителю ($5 + $14/км) событием `pay`.
- **Присед**: C / кнопка 🧎; медленнее, ниже силуэт и камера, меньше хитбокс для пуль.
- **Редактор персонажа**: пол, кожа, рост, телосложение, глаза, борода/помада, причёски (13), одежда; открывается при создании персонажа (соло и онлайн).
- **Поддержка** (`support.ts`): форма в планшете → Telegram Bot API всем, кто писал боту. Список chat_id хранится постоянно в скрытом описании бота (language_code `yo`), чтобы не теряться через 24 ч.
Проверки: `scripts/sharedtest.ts` (общие NPC, трафик и припаркованные машины), `scripts/nettest2.ts` (недвижимость, объявления, NPC, оплата, покупка — на реальном сервере).
